## 八、实践节点

### 节点 1：最小服务器

- 跑通健康检查。
- 返回内存文章数组。
- 用 Apifox 检查 200 和 404。

### 节点 2：真实数据库

- 用 Docker 启动 PostgreSQL。
- 用 Prisma Schema 和 Prisma Migrate 建立 `articles` 表。
- 用 Prisma Client 完成创建和查询，并查看生成的迁移 SQL。
- 重启服务器后数据仍存在。

### 节点 3：真实业务

- 增加标签关系。
- 增加草稿、发布和分页。
- 测试重复 slug 和不存在文章。

### 节点 4：身份和产品界面

- 增加管理员登录。
- Next.js 后台完成文章管理流程。
- 未登录时不能写入数据。

### 节点 5：可靠性

- 自动化测试覆盖核心边界。
- 环境变量和迁移可重复。
- README 能指导新环境启动。

## 小结

真正掌握的标准不是背出定义，而是：

```text
能用自己的话解释它解决什么问题
能指出它出现在哪个请求步骤和哪类文件中
能说清它接收什么、返回什么
能设计一个正常请求和一个错误请求验证它
```
