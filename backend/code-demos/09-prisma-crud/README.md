# 09 Prisma CRUD Demo

这是第 09 章的独立练习工程，用来第一次集中练习 Docker、PostgreSQL、TablePro、Prisma 7 和 Express CRUD。

它是进入 Mini CMS 之前的阶段性 CRUD 实操。按照第 09 章逐步练习后，目录会形成下面的结构：

```text
09-prisma-crud/
├── compose.yaml
└── server/
    ├── package.json
    ├── prisma/
    └── src/
```

`compose.yaml` 放在本目录根部；Node.js、Express 和 Prisma 代码放在 `server/` 中。

读完第 09A 章并能复述 Prisma 主线后，这次实操就完成了它的学习任务。接下来阅读后端学习路线的第 10 章，看清 demo 还存在哪些问题，以及 Mini CMS 后续怎样逐项解决。从阶段 3 开始，Zod、项目结构、管理页面、标签、登录和测试都只在 `mini-cms` 仓库中实践。
