# 从 Web 全栈到 Agent 开发

看到 Lauren Tan 从 React 相关工作转向 AI 产品，你会疑惑：跨度有多大？我只会调用大模型 API，也能做 Agent 吗？

这个系列从你的 Web 全栈经验出发，逐步讲清模型、工具、上下文、执行循环与评估。**全程沿用 TypeScript + Node.js，不要求学习 Python。**

实践是一个独立的 Markdown 笔记助手：搜索、读取、回答，再生成需要确认的修改建议。文章直接提供跟练步骤，你在自己的目录中逐步写出程序；不依赖 Mini CMS 或仓库内的完成版代码。

## 怎样学

先用熟悉的 Web 场景或生活类比建立直觉，再看真实数据流。工具调用可以类比填取书单，但最终要能说清：谁填参数，谁校验，谁取书，结果怎样返回。

循环、分支、状态与多方交互配有流程图。做完练习后合上文档，用自己的话复述；讲不清的地方，回到输入、代码和输出核对。

本系列保留文章和一个 `appendices/` 附录目录。评估用例就在第 07 章，招聘来源就在第 08 章，任务与交接示例就在协作附录里。
