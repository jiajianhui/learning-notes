# 本系列写作约定

- 系列独立于 `ai/` 和 Mini CMS；实践主线是本地 Markdown 学习笔记助手。
- 面向会 Web 全栈和调用模型 API 的读者，使用 TypeScript，先 CLI，Web 界面留作选做。
- 参照费曼学习法：从具体问题出发，用熟悉的比喻解释新概念，再对应真实机制、代码和结果。
- 类比要说明对应关系及必要的边界，不能把模型写成人类，也不能用比喻代替机制解释。
- 多角色交互、循环、条件分支与状态转换优先用 Mermaid 流程图或时序图；图后说明读法，不为简单一句话堆图。
- 官方工程资料应提炼成当前项目可验证的改进，注明来源和适用范围；区分通用原则、厂商产品操作与后续选做。
- 每章安排一个能动手验证的小练习，以及用自己的话复述的问题；复述不出来时指向应回看的代码或步骤。
- 实践先给最小完整链路，再扩展；不要要求读者先复制全部最终代码才能理解第一步。
- 明确区分“用开发 Agent 写软件”和“正在开发的笔记 Agent”，不要混用角色。
- 示例项目在 `code/note-agent/`；先读其 README 和 package.json。离线测试与真实模型评估分别报告。
- 多 Agent、Worktree、CI 是教学内容，不代表可以在学习笔记仓库直接建分支、调用多个 Agent、推送或提交。
- 根目录 README 维护入口，本目录 README 维护阅读顺序；所有实践步骤与实际示例保持一致。
