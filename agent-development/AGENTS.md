# 本系列写作约定

- 面向会 Web 全栈和模型 API 的读者，全程用 TypeScript/Node.js；Python 不作为本系列学习任务。
- 系列独立于旧 `ai/` 与 Mini CMS，实践主线是 Markdown 笔记助手。
- 本专题以文章为交付物，只保留 `appendices/` 作为子目录，不新增代码、来源、评估或模板目录。
- 实践直接在章节内逐步指导读者创建自己的项目，给出文件位置、完整可运行代码、命令与预期结果；不能依赖仓库中不存在的现成文件。
- 使用费曼式解释：具体问题 → 熟悉类比 → 真实对象与数据流 → 动手验证 → 自己复述。类比不能替代机制。
- 循环、分支、状态变化与多方交互使用必要的 Mermaid 图；简单动作不强行画图。
- 00～07 为通识与递进实践，08～13 为岗位补强；编程 Agent、Worktree、CI 放在协作附录。
- 评估用例并入对应章节，招聘来源就地引用，任务与交接示例放在附录正文。
- 招聘注明查阅日期、职级与来源限制；样本不能推出市场统计，不能合并不同方向要求为通用门槛。
- 修改代码块时同步相邻步骤和命令，必要时抽取到临时目录验证；验证产物不加入本仓库。
- 分开报告离线脚本、实际工具或协议、真实模型的验证范围，不把固定输出当成模型效果。
- 章节编号、内部链接与根入口保持一致。协作教学不等于授权在本仓库建分支、派发 Agent、提交或推送。
