## 本次实际验证的范围

- Node.js v24.14.1 环境安装配套依赖，生成锁文件；本轮在同一环境验证。
- `npm run check`：TypeScript 类型检查与 17 项离线测试全部通过；包括总结与工具模式的请求指令、请求失败、工具异常、轮次耗尽，以及 CLI 成功和失败后的日志落盘。
- `npm run demo`：模拟模型决策，真实执行临时文件搜索、读取、建议和确认写回。
- `npm run demo:failure`：模拟请求失败与连续工具失败，确认失败轮次保留 `errorCode`，并按上限停止。
- 本地 CLI 搜索、阅读及失败输入检查。
- 10 张 Mermaid 流程图与时序图通过 Mermaid 11 语法解析；逐图核对对应代码或教学步骤。未逐个验证不同 Markdown 阅读器的排版效果。
- 系列内部 Markdown 链接、标题层级、代码块配对与空白检查。

真实模型调用未运行，没有通过读取本机凭证来发起付费请求。因此不声明真实问答、提示词抗干扰或内容改写质量已通过评估；请按[用例表](./evals/用例与记录.md)实际核对。

## 示例的适用范围

这是小型、单用户、本地 CLI 教学项目，不是面向不可信本机进程的文件隔离系统。文件访问和修改检查覆盖课堂练习需要的路径、类型、大小和版本条件，没有实现多进程锁、长期任务恢复或大型知识库索引。

离线模拟能证明执行器怎样处理请求，不能证明模型为什么做出某个选择。回答内容的质量，必须结合原文与真实运行记录判断。
