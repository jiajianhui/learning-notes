# 07. 按当前问题找资料

有 Blender 基础时，优先补齐资产交付、PBR、灯光与 React 场景组织。不要先收藏几十个教程，再从头重复学习建模。

第一阶段从 [iPhone Duo 项目](./projects/01-iphone-duo/README.md) 开始：先读加载器、React 场景、动画与输入；Blender 导出和烘焙留到需要修改资产或进入第二阶段时。

## 官方文档的阅读顺序

| 当前阶段 | 资料 | 带着什么问题读 |
|---|---|---|
| 模型导出 | [Blender glTF](https://docs.blender.org/manual/en/latest/addons/scene_gltf2.html) | 哪些节点和材质通道能导出？ |
| 贴图烘焙 | [Blender Render Baking](https://docs.blender.org/manual/en/latest/render/cycles/baking.html) | 目标图像怎么选择，烘焙了哪些信息？ |
| 理解材质 | [MeshStandardMaterial](https://threejs.org/docs/pages/MeshStandardMaterial.html) | 每张贴图和材质参数分别控制什么？ |
| 颜色不一致 | [Three.js Color Management](https://threejs.org/manual/pages/color-management.html) | 输入、计算和输出各用什么空间？ |
| 接入 React | [R3F Installation](https://r3f.docs.pmnd.rs/getting-started/installation)、[Canvas](https://r3f.docs.pmnd.rs/api/canvas) | 版本如何配对，渲染器默认做了什么？ |
| 布光 | [Environment](https://drei.docs.pmnd.rs/staging/environment)、[Lightformer](https://drei.docs.pmnd.rs/staging/lightformer) | 环境反射与真实投影有什么区别？ |
| 交互 | [R3F Events](https://r3f.docs.pmnd.rs/api/events) | 射线事件如何穿透与冒泡？ |
| 编辑模型组件 | [gltfjsx](https://github.com/pmndrs/gltfjsx) | 如何保留节点、分组与局部变换？ |
| 网站边界 | [Next.js Lazy Loading](https://nextjs.org/docs/app/guides/lazy-loading) | 哪个组件在浏览器加载，哪些内容仍是普通页面？ |
| 优化 | [R3F Scaling Performance](https://r3f.docs.pmnd.rs/advanced/scaling-performance)、[glTF Transform](https://gltf-transform.dev/cli) | 慢在下载、绘制还是持续更新？ |

Blender 文档路径会随版本调整。找不到页面时从手册的版本选择器进入所用版本，再搜 glTF 或 Render Baking。旧教程中的面板位置也不一定与当前版本相同。

每读一页文档，回实验台改一个变量并写一句观察。比如读完 metalness，就对同一个几何体切换 0 与 1，同时保持灯光不变。

## 如果只选一套系统课程

可以优先看 Bruno Simon 的 [Three.js Journey](https://threejs-journey.com/)。其课程目录包含材质、环境、模型、Blender 烘焙、R3F、Drei、事件与后处理，与本路线比较吻合。

按你的基础，建议优先找这些主题，而不是机械从第一节刷到最后：

1. Materials、Textures、Environment / Realistic Render：解决表面与灯光。
2. Blender、Baking：分清资产烘焙与静态光照烘焙。
3. R3F、Drei、Load Models：把资产组织成 React 组件。
4. Mouse Events、Animation、Performance：完成可玩与交付。

这是付费课程候选，先看官方课程目录和可预览内容，判断讲解节奏是否适合自己。免费主线就是上面的官方文档，加上本目录的实验。WebGPU、TSL 和复杂 Shader 可以作为后续专题，当前手机项目不以它们为前置条件。

## 出现问题时按什么顺序查

| 问题 | 先做的一个动作 | 回看 |
|---|---|---|
| 页面只有黑色或空白区域 | 看控制台和画布容器高度，再检查模型请求 | [03](./03-Nextjs材质实验台.md) |
| 模型特别小或不在视野内 | 用 Bounds 自动取景，核对真实尺寸与模型位置 | [03](./03-Nextjs材质实验台.md) |
| 材质图案丢失 | 把同一 GLB 重新导入 Blender，检查导出结果 | [02](./02-Blender到网页的资产流程.md) |
| 金属全黑 | 打开已知可用的环境，保留其他变量 | [04](./04-材质灯光与色彩校准.md) |
| 光照烘焙后显得发脏 | 确认是否把带光照的图当作 Base Color 再次照明 | [01](./01-目标效果与工具选择.md) |
| 所有颜色都发灰或过亮 | 记录输入贴图空间、tone mapping、曝光和输出流程 | [04](./04-材质灯光与色彩校准.md) |
| 法线凹凸方向不对 | 核对切线空间与 +Y 约定，再看缩放和法线 | [02](./02-Blender到网页的资产流程.md) |
| 替换屏幕图后上下颠倒 | 检查 glTF 替换贴图的 flipY 与 UV | [04](./04-材质灯光与色彩校准.md) |
| 一个按钮影响多个部件 | 检查材质是否共享，事件是否穿透 | [05](./05-按键屏幕与机械交互.md) |
| 翻盖绕中心乱转 | 在 Blender 中单独旋转轴心父级，看结构是否正确 | [05](./05-按键屏幕与机械交互.md) |
| demand 模式下动画只动一帧 | 检查第一帧与后续帧是否都调用 invalidate | [06](./06-数字手办项目与验收.md) |
| 压缩后无法加载或按钮消失 | 回到未压缩基线，查解码器与结构优化 | [06](./06-数字手办项目与验收.md) |

## 回顾时能回答这六个问题

1. 为什么一份 GLB 不等于 Blender 的最终渲染画面？
2. 烘焙 Base Color 与烘焙整套灯光，分别保存了什么？
3. 为什么金属材质需要环境中的亮暗结构？
4. 为什么 roughness 图不能统一标成 sRGB？
5. 一个点击如何从 React 状态变成屏幕和机械部件的变化？
6. 为什么 5 MB 的模型也可能在手机上很慢？

能用自己做过的对照实验回答这些问题，再拿一件新的物体走完整条流程。这样学到的能力才可以迁移到下一个作品。
