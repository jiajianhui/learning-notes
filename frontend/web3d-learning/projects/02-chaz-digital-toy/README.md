## 参考站里可以确认什么

CHAZ 作者在 [B 站作品介绍](https://www.bilibili.com/video/BV19CQTY7EDS/) 中将 N93i 称为 3D 数字手办。这个定位适合第二阶段项目：除了展示外观，还要让物件可以被操作。

2026-11-25 查看 [2025-07-30 的手机博物馆存档](https://web.archive.org/web/20250730065148/https://chaz.fun/phonemuseum/)，列表中有 Nokia 3250、5300、N93i、5310 和 Lumia 1020。卡片能看到金属边缘、深色屏幕和不同机身配色；部分标签标注变形、滑盖和可开机。

[N93i 的 2025-08-06 详情存档](https://web.archive.org/web/20250806055326/https://chaz.fun/phone/n93i/) 本次停在加载进度，未能完整体验模型交互。因此下面是为同类效果设计的学习方案，不是对原站源码或材质参数的还原。

你提供的聊天截图只能确认作者建议掌握相关软件与框架、查官方文档；它没有说明是否用了全场景烘焙、哪种 HDRI、哪个 React 库，或是否使用游戏引擎。不能据此给作者补一套技术栈。

## 两个阶段的衔接

第一阶段的交互主要是“怎样看产品”：旋转、折叠、换姿态。第二阶段进一步做“怎样操作物件”：按下电源键后屏幕改变、滑盖打开后露出按键等。

先完成一件设备。能稳定复用模型加载、灯光场景、状态与机械动作之后，再做手机博物馆式的列表与多件作品。当前文档不表示这些后续功能已经实现。
