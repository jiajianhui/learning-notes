# iPhone Duo 工程学习路线

先按[项目说明](../README.md)启动展台。把合拢的手机拖到侧面，观察银框亮带；再连续点两次「下一姿态」，观察第二次点击时机身从哪里开始转。下面五篇按第一次跟读的顺序编号。所有命令都在项目根目录运行。

| 跟读章节 | 打开哪段工程 | 用什么动作检验理解 |
|---|---|---|
| [01 · Akash 折叠展示拆解](./01-Akash折叠展示拆解.md) | [展台控件](../components/product-demo.tsx)、[姿态配置](../lib/poses.ts) | 连续切换两次姿态，能分别解释菜单展开和机身转向由谁驱动 |
| [02 · 模型资产与格式接入](./02-模型资产与格式接入.md) | [资产清单](../asset-manifest.json) | 在 Network 找到 glTF 和外部依赖，能指出铰链动画来自哪个文件 |
| [03 · 模型加载与姿态动画](./03-模型加载与姿态动画.md) | [场景与逐帧更新](../components/phone-scene.tsx) | 从「坐姿」按钮跟到骨骼采样，能区分开合、整机朝向和取景的变化 |
| [04 · 材质灯光与清晰度](./04-材质灯光与清晰度.md) | [环境图生成](../components/use-studio-maps.ts)、[材质分配](../lib/model-materials.ts) | 固定侧面，只改外框粗糙度，预测亮带边缘的变化并恢复原值 |
| [05 · 拖动吸附与项目验收](./05-拖动吸附与项目验收.md) | [指针事件](../components/use-product-drag.ts)、[运动计算](../lib/drag-motion.ts) | 对比慢拖和快甩，解释松手后的惯性、吸附与侧面俯仰，再记录真机手感和帧耗时 |

[展示效果与交互调校复盘](./展示效果与交互调校复盘.md)按症状查阅。遇到银框发黑、屏幕强光、Logo 太淡或侧面停靠角度异常时，先找到相似现象，再核对当时的假设、最后采用的方案和验证动作。
