# 11. 常见误区：用七层体系重新排疑

## 问题背景

现代前端的误区，大多来自一件事：

```text
这些技术经常一起出现，所以初学者以为它们是同一类。
```

比如：

```text
Vite + React
React + Next
Vue + Nuxt
TypeScript + Vue
```

本文属于第七层：学习方法层，专门用七层地图排疑。

---

## 核心解释

先看分层：

```text
第六层：应用框架层    Next.js / Nuxt.js
第五层：应用组织层    路由 / 状态管理 / 组件通信
第四层：工程化层      Vite / 构建工具
第三层：UI 框架层     React / Vue
第二层：语言增强层    TypeScript
第一层：基础层        HTML / CSS / JavaScript / DOM
```

第七层是学习方法：看项目、判断技术栈、规划路线。

判断任何疑问，先问：

```text
它属于哪一层？
```

---

## 常见问题

### 1. Vite 是不是 React/Vue？

不是。

```text
Vite：工程化层，负责开发服务器、转换、打包
React/Vue：UI 框架层，负责组件和界面
```

所以可以有：

```text
Vite + Vanilla TS
Vite + React
Vite + Vue
```

看到 `vite.config.ts`，不能直接判断用了 React/Vue。

---

### 2. React 和 Next.js 是什么关系？

```text
React：UI 框架
Next.js：基于 React 的应用框架
```

写 Next 仍然要写 React 组件。

Next 多解决：

```text
路由约定
页面结构
SSR / SSG
应用组织
```

---

### 3. Vue 和 Nuxt.js 是什么关系？

```text
Vue：UI 框架
Nuxt.js：基于 Vue 的应用框架
```

写 Nuxt 仍然要写 Vue 组件。

---

### 4. TypeScript 是不是新前端？

不是。

对前端学习来说，先这样理解：

```text
TypeScript = JavaScript + 类型系统
```

它属于语言增强层，不负责 UI，也不负责打包。浏览器最终运行的通常还是 JavaScript。

---

### 5. 会 React 还要不要学原生 JavaScript？

要。

React 代码里到处都是 JavaScript：

```text
函数
数组
对象
模块
异步
闭包
事件
```

不会 JS，就会把普通 JS 问题误以为是 React 问题。

---

### 6. 会 Vue 学 React 难不难？

不是从零开始，但要换表达方式。

能迁移：

```text
组件化
props
状态驱动视图
事件处理
路由和状态管理意识
```

要重学：

```text
JSX / TSX
Hooks
React 状态更新方式
React 生态选择
```

---

### 7. 为什么有些项目没有 React/Vue？

因为不是所有前端项目都需要 UI 框架。

可能只是：

```text
HTML + CSS + JavaScript
Vite + Vanilla TS
```

没有 React/Vue，不代表不是前端项目，只是没有第三层 UI 框架。

---

### 8. 为什么有 vite.config.ts 但不是 React/Vue？

因为 Vite 可以服务 Vanilla TS。

```text
main.ts
document.querySelector
addEventListener
vite.config.ts
没有 react/vue
```

这就是工程化层 + 原生 DOM，不是 UI 框架项目。

---

### 9. 为什么有些项目只有 HTML、CSS、main.ts？

这通常是：

```text
基础层 + TypeScript + 工程化层
```

也就是：

```text
HTML / CSS / DOM
TypeScript
Vite 或类似工具
```

它没有 React/Vue，所以不是 UI 框架项目。它适合练 DOM、事件、TS 基础和 Vite 启动流程。

---

### 10. 为什么早期没有 Node，现在前端项目离不开 npm？

早期：

```text
HTML
CSS
JavaScript
浏览器直接打开
```

现代：

| 现代写法 | 为什么需要工具 |
|---|---|
| JSX / TSX | 要转换 |
| `.vue` | 要解析 |
| TypeScript | 要检查和转换 |
| npm 包 | 要管理依赖 |
| 热更新 | 要开发服务器 |
| 打包 | 要构建工具 |

所以：

```text
React/Vue 管 UI
Node.js 跑工具
npm/pnpm 管依赖
Vite 管开发和打包
```

---

### 11. 框架、库、工具、应用框架有什么区别？

| 名词 | 通俗理解 | 例子 |
|---|---|---|
| 库 | 提供某类能力，你主动调用 | 工具函数库 |
| UI 框架 | 提供构建界面的方式 | React / Vue |
| 工具 | 帮开发、检查、转换、打包 | Vite |
| 应用框架 | 规定应用结构和运行方式 | Next / Nuxt |

边界有时不绝对，但入门阶段先这样分，就不容易乱。

---

### 12. 初学者先学框架还是基础？

先学基础，但不用等基础完美。

合理节奏：

```text
HTML/CSS/JS 基础
原生小 demo
TypeScript 和 Vite
React 或 Vue
Router / Store
Next / Nuxt
```

基础决定你能不能看懂问题原因，框架帮助你进入现代项目。

---

## 技术关系

### 一张排疑表

| 误区 | 正确理解 |
|---|---|
| Vite 是 React/Vue | Vite 第四层，React/Vue 第三层 |
| Next 和 React 同一类 | Next 第六层，React 第三层 |
| Nuxt 和 Vue 同一类 | Nuxt 第六层，Vue 第三层 |
| TypeScript 是框架 | TypeScript 第二层 |
| 路由就是框架本体 | 路由是第五层 |
| 状态管理必须一开始学 | 复杂共享数据时再学 |
| 会框架就不用 JS | 框架依赖 JS |

---

## 学习建议

遇到新名词，填这张表：

| 问题 | 示例 |
|---|---|
| 它属于哪一层？ | Vite 属于工程化层 |
| 它解决什么问题？ | 启动开发服务器和打包 |
| 它依赖什么？ | Node 工具链、JS 模块 |
| 它常和谁搭配？ | React、Vue、Vanilla TS |
| 项目里怎么看出来？ | `scripts.dev`、`vite.config.ts` |

先建立位置感，再学 API。

---

## 小结

排疑的核心不是背定义，而是分层。

```text
Vite 和 React/Vue 不是同一层
React/Vue 和 Next/Nuxt 不是同一层
TypeScript 和 React/Vue 不是同一层
Router/Store 是应用组织层
学习方法层负责把它们串起来
```

先分层，再看关系，很多问题会自然变清楚。
