# 10. 现代前端推荐学习路线

## 问题背景

现代前端难的不是技术少，而是顺序乱。

常见纠结：

```text
先学 JS 还是 React？
TypeScript 要不要一开始学？
Vite 什么时候学？
Next / Nuxt 要不要现在学？
```

本文属于第七层：学习方法层。

---

## 核心解释

### 1. 学习顺序和项目选型不是一回事

学习时建议从底层往上：

```text
HTML / CSS / JS / DOM
TypeScript
React 或 Vue
Vite
Router / Store
Next 或 Nuxt
```

做项目时通常从目标倒推：

```text
我要做什么
需要什么应用形态
选择对应技术组合
再补缺的基础
```

一句话：

```text
学习时打地基，做项目时看目标。
```

---

### 2. 理解顺序和动手顺序也不是一回事

不用把每一层学到完美才进入下一层。

更适合初学者的是循环推进：

```text
做原生 demo
看基础层
做 Vite + TS demo
看 TypeScript 和工程化
用 Vue 或 React 重写同一功能
再加 Router / Store
最后再看 Next / Nuxt
```

你的 `minimal-frontend-demo` 就是干这个用的。

---

## 技术关系

### 每层学到什么程度

| 层 | 先学到什么程度 |
|---|---|
| HTML | 常见结构、表单、语义化 |
| CSS | 盒模型、Flex、Grid、响应式 |
| JavaScript | 函数、数组、对象、DOM、事件、异步 |
| TypeScript | 基本类型、对象类型、函数类型、props 类型 |
| React/Vue | 组件、状态、事件、列表、表单、props |
| Vite | `npm run dev`、`build`、配置文件、插件线索 |
| Router/Store | 页面切换、局部状态、共享状态 |
| Next/Nuxt | 文件路由、CSR/SSR/SSG、应用结构 |

---

### 不同目标怎么走

| 目标 | 推荐路线 | 备注 |
|---|---|---|
| 普通网页 | HTML -> CSS -> JS DOM -> 必要时 Vite | 不一定需要框架 |
| 后台管理系统 | JS/TS -> React/Vue -> Vite -> Router -> Store | 页面多、表单多 |
| 官网 / 作品集 | HTML/CSS -> React/Vue -> CSR/SSR/SSG -> Next/Nuxt | 重视展示和 SEO 时再考虑 |
| 复杂 Web App | TS -> React/Vue -> Router/Store -> 项目结构 | 重点是状态和模块边界 |
| 现代全栈前端 | TS -> React/Vue -> 调 Express API -> 再选 Next/Nuxt | 后端已定 Node + Express |

更具体一点：

```text
普通网页：
先把结构和样式写稳 -> 加少量 DOM 交互 -> 需要工程化时再用 Vite

后台管理系统：
先会组件化 -> 再做多页面路由 -> 最后处理共享状态、表单、表格

官网 / 作品集：
先重视视觉和内容结构 -> 再组件化复用区块 -> SEO/内容多时考虑 Next/Nuxt

复杂 Web App：
先练 TS 和组件模型 -> 再练状态、路由、错误状态 -> 最后考虑模块边界

现代全栈前端：
先做纯前端页面 -> 再调用 Express API -> 需求明确后再决定是否上 Next/Nuxt
```

---

### 什么时候学 TypeScript

在 JavaScript 基本稳定后学。

你不需要等很久，但至少要先懂：

```text
函数
对象
数组
模块
Promise / async await
基本 DOM 或组件写法
```

结合你的 Swift 背景，做正式项目时 TypeScript 可以作为默认选择。

---

### 什么时候学 Next / Nuxt

先能写普通 React/Vue 项目，再学 Next/Nuxt 更稳。

因为 Next/Nuxt 里仍然要写：

```text
组件
props
state/ref
事件
列表
表单
```

如果 UI 框架没理解，学应用框架会混。

---

## 学习建议

现在这阶段，不要急着做最终网站选型。

更好的节奏是：

```text
读 01 / 02
复盘原生 demo
读 03 / 04 / 06
做 02-vite-vanilla-ts
再进入 Vue 或 React
```

每学一个技术都问：

```text
它解决什么问题？
它属于哪一层？
它替我省掉了原生写法里的什么麻烦？
```

---

## 小结

现代前端学习最重要的是顺序感。

```text
学习时：从底层往上理解
做项目时：从目标往下组合
读项目时：从 scripts 和入口文件反推
```

能在这三个方向之间切换，前端就不再是一堆名词。
