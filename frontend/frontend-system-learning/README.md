# 现代前端体系与学习方法（七层技术地图）

## 现代前端七层技术地图

```text
第七层：学习方法层（看项目/判断技术栈/规划学习）
第六层：应用框架层（Next.js / Nuxt.js）
第五层：应用组织层（路由 / 状态管理 / 组件通信）
第四层：工程化层（Vite / 开发服务器 / 构建打包）
第三层：UI 框架层（React / Vue）
第二层：语言增强层（TypeScript）
第一层：基础层（HTML / CSS / JavaScript / DOM）
```

本套文档聚焦“排疑 + 建图”：帮你分清技术层次、建立学习顺序、学会通过项目文件判断技术栈。

- 学习时：建议自下而上理解。
- 做项目时：通常自上而下组合。

## 推荐阅读顺序
01 → 10 + glossary + exercises。

## 小结
核心目标不是背概念，而是建立“分层认知”。
