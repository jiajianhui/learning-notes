# 最小前端 Demo

这个目录对应 `frontend-system-learning/00-阅读导引和最小实战主线.md`。

练习原则：

```text
一个小项目，多种实现方式。
```

也就是：用同一个“计数器 + 列表”功能，分别用不同技术阶段实现一遍。

目录规划：

```text
01-html-css-js/        # 原生 HTML / CSS / JavaScript
02-vite-vanilla-ts/    # 后续：Vite + Vanilla TypeScript
03-vue/                # 后续：Vue
04-react/              # 后续：React
05-router/             # 后续：前端路由
06-state-management/   # 后续：状态管理
07-next-nuxt-reading/  # 后续：Next / Nuxt 结构阅读
```

建议按文档节点推进：

```text
读完 02：做 01-html-css-js/
读完 06：做 02-vite-vanilla-ts/
读完 05 + 06：再选 Vue 或 React 做框架版
读完 07：再加路由和状态管理
```

现在先把 `01-html-css-js/` 吃透。不要急着进入 Vite、Vue 或 React。
