# 04. Making Software 风格：让页面有作者气质

## 问题背景

前三个项目分别练了：

```text
极简列表
数据内容
图片文章
```

最后这一站开始练更难的东西：

```text
页面不仅要清楚，还要有自己的性格。
```

参考网站：

```text
https://www.makingsoftware.com/
```

做一个有强烈个性、章节感和视觉叙事节奏的网站。

这次不是单纯练“干净”，而是练：

- 个性化视觉语言
- 图形和文字的组合
- 章节节奏
- 长页面阅读体验
- 克制但有记忆点的动效

---

## 核心解释

### 1. 这个项目练什么：视觉叙事和章节节奏

普通页面常见问题是：

```text
每个 section 都很像
每段内容都只是标题加正文
页面越长越无聊
```

这个项目要反过来练：

```text
每个章节有变化
视觉元素和文字有关
滚动时有阅读节奏
页面像一个完整作品
```

一句话：

```text
这次练的是：网站不只是排版，也是表达。
```

---

### 2. 首页应该长什么样：像一本能滚动阅读的小书

建议首页包含：

- 强标题首屏
- 章节导航
- 多个内容章节
- 图形/插画占位
- quote 或重点语句
- 结尾 CTA

首屏要有记忆点。

中间章节要有起伏。

结尾要有收束，而不是突然结束。

---

### 3. 核心组件：围绕章节拆

- `SiteHeader`
- `ChapterHero`
- `ChapterNav`
- `StorySection`
- `VisualPanel`
- `QuoteBlock`
- `SiteFooter`

---

## 技术关系

### 1. 本地数据：用章节数组组织页面

先用本地数组：

```ts
type Chapter = {
  number: string;
  title: string;
  summary: string;
  accent: string;
};
```

这次的数据不一定很多。

重点是让每个章节有自己的布局和视觉重点：

```text
Chapter 数据
-> StorySection
-> VisualPanel
-> 锚点导航
-> 滚动阅读
```

---

### 2. Tailwind 重点：章节、图形和滚动位置

- `min-h-screen`
- `grid`
- `sticky`
- `mix-blend-*`
- `border-*`
- `rotate-*`
- `font-serif` / `font-mono`
- `tracking-*`
- `scroll-mt-*`

---

### 3. 交互重点：动效要服务阅读

- 章节导航 sticky
- 点击锚点跳转
- section hover 或 focus 状态
- 轻微滚动进场动画

如果要加动画，先问：

```text
它有没有帮助用户理解当前章节？
```

如果没有，就先不要加。

---

## 学习建议

### 1. 先做章节结构，再做视觉个性

建议顺序：

```text
先写章节数据
-> 做 hero
-> 做 3 到 5 个 StorySection
-> 加 ChapterNav
-> 做锚点跳转
-> 调整每个章节的视觉差异
-> 最后加轻动效
```

### 2. 完成标准

- 页面有明确章节感
- 首屏有记忆点
- 每个 section 的布局不完全重复
- 动效不喧宾夺主
- 整体不像模板站，而像一个有作者气质的网站

---

## 小结

这个项目的目标不是做一个“功能更多”的网站，而是学会：

```text
怎么让页面有叙事节奏和作者气质。
```

这是四个练习里最难的一站。不要急着炫技，先让每个章节都有存在的理由。
