# 03. Lux 风格：图片和文章怎么做出质感

## 问题背景

前两个项目主要练列表、卡片和数据。

这一站开始练另一种能力：

```text
图片很多时，页面怎么不乱；
文章很多时，首页怎么有节奏；
产品感和编辑感怎么放在一起。
```

参考网站：

```text
https://www.lux.camera/
```

这个项目不急着做博客系统。先做静态首页，练出摄影、产品、文章结合的质感。

---

## 核心解释

### 1. 这个项目练什么：大图、文章卡片和首页节奏

这次重点是：

- 大图视觉
- 文章卡片
- 首页节奏
- 品牌质感
- 图片和文字的关系

一句话：

```text
这次练的是：图片不是装饰，而是页面气质的一部分。
```

---

### 2. 首页应该长什么样：先有强首屏，再有文章节奏

建议首页包含：

- 固定或半透明顶部导航
- 大图 hero
- 最新文章区
- 不规则图片卡片网格
- 产品入口区
- newsletter 或页尾

首屏要先让用户知道：

```text
这是一个和摄影、产品、创作有关的网站。
```

后面的文章区要让用户觉得：

```text
内容很多，但每篇文章都有被认真摆放。
```

---

### 3. 核心组件：围绕图片内容拆

- `SiteHeader`
- `HeroSlider` 或 `HeroFeature`
- `ArticleCard`
- `EditorialGrid`
- `ProductLink`
- `NewsletterBlock`
- `SiteFooter`

第一版可以先不做真正轮播。

先做一个静态 `HeroFeature`，视觉稳定后再考虑 `HeroSlider`。

---

## 技术关系

### 1. 本地数据：用文章数组模拟内容

先用本地数组：

```ts
type Article = {
  title: string;
  tag: string;
  excerpt: string;
  image: string;
  date: string;
  featured?: boolean;
};
```

数据先服务页面，不要反过来被数据结构拖住。

你真正要练的是：

```text
文章数据
-> featured 文章
-> 普通文章网格
-> 图片比例
-> hover 浮层
```

---

### 2. Tailwind 重点：图片比例、遮罩和 hover

- `aspect-*`
- `object-cover`
- `absolute`
- `inset-0`
- `bg-gradient-to-t`
- `backdrop-blur`
- `group-hover:*`
- `scale-*`
- `transition-transform`

---

### 3. 交互重点：图片动效要克制

- 图片 hover 轻微放大
- 文章卡片文字浮层
- 导航背景模糊
- hero 切换可以先做静态，后续再补轮播

不要让图片 hover 太夸张。

这一类网站的动效更适合：

```text
慢一点
轻一点
少一点
```

---

## 学习建议

### 1. 先把图片比例调顺

建议顺序：

```text
先做 header
-> 做 hero 大图
-> 做 3 到 6 篇文章卡片
-> 调整图片比例
-> 做文章网格
-> 加 hover
-> 做移动端排序
```

### 2. 完成标准

- 首屏有强图片视觉
- 文章卡片有层级，不只是普通列表
- 图片比例统一且裁切自然
- 移动端不会因为图片过大而混乱
- 整体有摄影/编辑站的质感

---

## 小结

这个项目的目标不是做完整博客，而是学会：

```text
图片、文章和产品入口如何共同建立网站气质。
```

如果能把这个项目做稳，后面做产品官网、摄影站、作品集都会更有把握。
