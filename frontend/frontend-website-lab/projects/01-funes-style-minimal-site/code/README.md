## 01、设计观察

页面没有图片、没有阴影、没有边框、没有颜色

字体元素间无对比（颜色、大小一致）、少量不同颜色的文字代表不同状态

整体布局严谨，整体左对齐，不同区块间留白明显

无动效、交互简单、hover和active只是简单颜色变化

自适应移动端

## 03、常见问题
在本地开发时，如果手机通过局域网 IP 访问电脑上的 Next dev server，可能会被 Next 的开发模式跨源限制拦截部分开发资源，导致页面交互异常；可以在 `next.config.ts` 中配置允许的开发来源，例如 `allowedDevOrigins: ["172.20.10.5"]`，然后重启服务生效。正式部署后通常不会有这个问题。
