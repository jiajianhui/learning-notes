# 01. Funes 风格：极简列表也能有秩序

## 问题背景

很多人一想到“好看的网站”，第一反应是大图、动效、渐变、卡片和复杂布局。

但 `funes.matsu.io` 提醒你另一件事：

```text
一个网站可以几乎没有装饰，
仍然靠字体、密度、对齐和 hover 做出高级感。
```

参考网站：

```text
https://funes.matsu.io/
```

这个项目适合作为第一站，因为它不会被图片和动效干扰。你要先练会：

```text
只靠结构和 CSS，让信息变得清楚、冷静、有秩序。
```

---

## 核心解释

### 1. 这个项目练什么：低装饰下的秩序感

这不是练炫酷效果，而是练这些基本功：

- 字体尺度
- 列表密度
- hover 状态
- 分类导航
- 低装饰下的秩序感

一句话：

```text
越极简，越考验间距、对齐和状态反馈。
```

---

### 2. 首页应该长什么样：像一个可浏览的档案列表

建议首页包含：

- 顶部标题栏
- 一级分类导航
- 二级状态导航
- 主列表
- 简短页尾

页面重点不是“模块很多”，而是让用户能快速扫读。

---

### 3. 核心组件：先拆列表和导航

- `SiteHeader`
- `PrimaryNav`
- `SecondaryNav`
- `EntryList`
- `EntryRow`
- `SiteFooter`

如果第一次写时组件拆不顺，可以先都写在 `page.tsx` 里。等列表行重复稳定后，再把 `EntryRow` 抽出来。

---

## 技术关系

### 1. 本地数据：用数组模拟内容

先用本地数组：

```ts
type Entry = {
  year: string;
  category: string;
  status: "todo" | "doing" | "done";
  title: string;
  author?: string;
  source?: string;
};
```

这一步先不做数据库。

你要练的是：

```text
数据数组
-> map 渲染
-> 分类筛选
-> active 状态
```

---

### 2. Tailwind 重点：小字号、高密度、细反馈

- `font-mono`
- `text-xs`
- `leading-5`
- `grid`
- `grid-cols-*`
- `divide-y`
- `hover:bg-*`
- `transition-colors`

注意不要把字号放得太大。

这个项目的味道来自：

```text
小字号
细边框
紧行高
清晰 hover
稳定网格
```

---

## 学习建议

### 1. 先做静态版，再做分类状态

建议顺序：

```text
先写 header
-> 写一组固定列表
-> 调整字体和行高
-> 加 hover
-> 加分类导航
-> 用数据数组渲染
-> 加 active 状态
```

### 2. 完成标准

- 桌面端列表有清晰列结构
- 移动端列表仍然可读
- hover 时有轻微但明确的反馈
- active 分类状态清楚
- 页面不依赖图片也有视觉完成度

---

## 小结

这个项目的目标不是“做一个简单页面”，而是学会：

```text
没有复杂视觉素材时，怎么靠排版和信息结构撑住页面。
```

如果这个项目做得舒服，后面做卡片、图片和动效时才不会乱。
