# 项目：网站练习与最终个人网站

## 问题背景

这里放四个网站练习项目和一个最终个人网站项目。

它们不是随便排列的，而是按难度和目标推进：

```text
极简信息站
-> 数据型内容站
-> 图片编辑类内容站
-> 视觉叙事站
-> 最终个人网站
```

前四个项目是能力练习，第五个项目是最终合成。

## 核心解释

### 1. 项目顺序

1. [01-funes-style-minimal-site](./01-funes-style-minimal-site/)
2. [02-aeroprecipe-style-data-site](./02-aeroprecipe-style-data-site/)
3. [03-lux-style-editorial-site](./03-lux-style-editorial-site/)
4. [04-makingsoftware-style-visual-site](./04-makingsoftware-style-visual-site/)
5. [05-personal-lux-style-site](./05-personal-lux-style-site/)

每个目录先放项目 brief。真正开始写代码时，可以直接在对应目录里初始化 Next.js 项目。

## 技术关系

默认技术栈：

```text
Next.js + React + TailwindCSS
```

默认命令：

```bash
npx create-next-app@latest .
```

然后围绕项目 brief 逐步实现。

## 小结

做前四个练习时先按 brief 完成首页，不要一开始就做大而全；最终项目再扩展到多页面成品站。

这一阶段先追求：

```text
页面像样
-> 气质接近
-> 交互舒服
-> 提炼能迁移到个人网站的能力
-> 最后合成自己的成品站
```
