# Projects：四个网站临摹项目

## 问题背景

这里放四个网站临摹实战项目。

它们不是随便排列的，而是按难度推进：

```text
极简信息站
-> 数据型内容站
-> 图片编辑类内容站
-> 视觉叙事站
```

## 核心解释

### 1. 项目顺序

1. [01-funes-style-minimal-site](./01-funes-style-minimal-site/)
2. [02-aeroprecipe-style-data-site](./02-aeroprecipe-style-data-site/)
3. [03-lux-style-editorial-site](./03-lux-style-editorial-site/)
4. [04-makingsoftware-style-visual-site](./04-makingsoftware-style-visual-site/)

每个目录先放项目 brief。真正开始写代码时，可以直接在对应目录里初始化 Next.js 项目。

## 技术关系

默认技术栈：

```text
Next.js + React + TailwindCSS
```

默认命令：

```bash
npx create-next-app@latest .
```

然后围绕项目 brief 逐步实现。

## 小结

做项目时先按 brief 完成首页，不要一开始就做大而全。

这一阶段先追求：

```text
页面像样
-> 气质接近
-> 交互舒服
-> 再慢慢补功能
```
