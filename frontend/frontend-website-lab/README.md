# Next.js + Tailwind：用项目练出好网站的感觉

## 问题背景

前面的 `frontend-system-learning` 解决的是：

```text
现代前端有哪些层？
每一层解决什么问题？
React、Vue、Vite、Next、Nuxt 之间是什么关系？
```

这套文档从这里开始换一个目标。

现在不再继续补基础课，而是进入真实网站练习：

用 Next.js + TailwindCSS 做出接近这些优秀网站的视觉、版式、交互和品味：

- https://www.lux.camera/
- https://funes.matsu.io/
- https://aeroprecipe.com/
- https://www.makingsoftware.com/

更长期的目标是：

```text
做出自己的个人网站，
用来放个人产品、文章、创作记录和项目沉淀。
```

其中 `lux.camera` 是最接近长期目标的参考形态：它既有产品入口，也有文章内容，还有统一的品牌气质。

主线先记这一条：

```text
不是复刻原站技术栈
-> 而是学习优秀网站的设计判断
-> 每个练习都沉淀到自己的个人网站
-> 最后做出一个 Lux 气质的个人网站成品
```

这套目录不只是“四个临摹项目”。更准确地说，它是：

```text
四个能力练习
+ 一个最终个人网站项目
```

前四个项目分别练排版、数据、图片和叙事；最后把这些能力合成到自己的个人网站里。

未来内容管理可以先记成这一条：

```text
现在先用本地数组、JSON、Markdown 模拟内容
-> 以后再用 Node.js + Express + PostgreSQL 动态管理内容
```

## 核心解释

### 1. 这套目录解决什么问题：把审美拆成能写的代码

这轮练习不急着做 CMS、后端、数据库。

先把重点放在这些问题上：

- 页面结构为什么舒服
- 字体、间距、颜色为什么高级
- 卡片、列表、导航、图片如何组织
- hover、滚动、切换、筛选这些交互如何克制地增强体验
- 如何用 Next.js + TailwindCSS 把这些设计判断落到代码里

一句话：

```text
先做出好看的前端页面，再考虑复杂功能。
```

对最终个人网站来说，先要练出来的是这些能力：

| 个人网站模块 | 现在对应练什么 |
|---|---|
| 个人产品展示 | 产品入口、视觉卡片、CTA、品牌气质 |
| 文章和笔记 | 编辑类排版、文章列表、详情页结构 |
| 项目沉淀 | 高密度列表、分类、筛选、标签 |
| 个人表达 | 章节叙事、视觉语言、滚动节奏 |

### 3. 这一阶段默认用什么技术：先固定 Next.js + TailwindCSS

默认技术栈：

```text
Next.js + React + TailwindCSS
```

当前阶段先这样取舍。

- 用本地数组、JSON 或 Markdown 作为内容数据
- 用 Tailwind 写主要样式
- 必要时补少量 CSS 变量或全局样式
- 暂不做登录、发布系统、评论系统、后台管理
- 暂不追求像素级复制，追求结构、气质和交互接近

## 技术关系

### 1. 项目怎么推进：四个练习，最后合成一个个人网站

建议顺序：

```text
01-funes-style-minimal-site
-> 极简信息站：练字体、列表、密度、hover、信息架构

02-aeroprecipe-style-data-site
-> 数据型内容站：练卡片、筛选、侧栏、响应式布局

03-lux-style-editorial-site
-> 图片编辑类内容站：练大图、文章卡片、首页视觉节奏

04-makingsoftware-style-visual-site
-> 视觉叙事站：练章节、插画/图形、滚动节奏、个性化表达

05-personal-lux-style-site
-> 最终个人网站：把前四站学到的能力合成自己的作品
```

先做极简，再做数据，再做图片内容，最后做视觉叙事。

但不要把前四个项目理解成互不相关的临摹。每做完一个项目，都要问：

```text
这个项目里哪 1 到 2 个能力，能迁移到我的个人网站？
```

最终目标不是“我临摹过四个网站”，而是：

```text
我能做出一个有产品入口、有文章内容、有项目沉淀、有个人气质的网站。
```

---

### 2. 每个项目至少做到什么程度

每个项目至少做到：

| 要求 | 说明 |
|---|---|
| 完整首页 | 不是零散组件 |
| 响应式 | 移动端和桌面端都能看 |
| 核心结构 | 有导航、内容区、页尾 |
| 核心组件 | 至少实现 2 个可复用组件 |
| 交互细节 | 至少实现 2 个 hover、sticky、drawer、filter 等细节 |
| 项目复盘 | 写清楚参考站、练习重点、问题，以及能迁移到个人网站的能力 |

不用一开始就完美。

先做出来，再迭代品味。
