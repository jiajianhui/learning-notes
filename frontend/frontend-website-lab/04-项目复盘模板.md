# 04. 项目复盘：把具体观察留下来

## 问题背景

做完一个页面之后，如果只是说“做完了”，很快就会忘记这次到底学到了什么。

这轮练习的复盘不是写总结给别人看，而是帮你留下两类东西：

```text
这次学到的代码经验
这次学到的设计观察
```

主线先记这一条：

```text
项目不是做完就结束
-> 复盘能把临摹变成自己的观察
```

## 学习建议

### 1. 不要写空话

不要只写：

```text
学到了很多。
页面还可以。
以后继续努力。
```

要写具体：

```text
这次终于理解了为什么列表页要控制行高。
图片卡片的高级感不来自阴影，而来自比例、裁切和文字压在正确的位置。
移动端不是把桌面端缩小，而是重新排序内容。
```

### 2. 每个项目都至少写三条设计观察

可以按这个句式写：

```text
我原来以为 __，这次发现 __。
这个页面高级不是因为 __，而是因为 __。
下次我会优先检查 __。
```

---

## 小结

复盘不是写总结给别人看，而是帮你积累自己的审美观察。

每做完一个项目，都应该留下三类资产：

- 一套能复用的代码经验
- 一组更清楚的设计观察
- 一条能迁移到个人网站的具体线索
