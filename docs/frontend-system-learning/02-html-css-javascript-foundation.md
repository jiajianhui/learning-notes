# 02 HTML / CSS / JavaScript 基础关系

> 所属层级：**第一层：基础层**。

## 问题背景

很多人学了 React/Vue 后会觉得“原生基础不重要”。这往往会导致：
- 排错困难
- 无法理解框架底层行为
- 面对非框架项目时无从下手

## 核心解释

### HTML：结构
定义内容语义与页面骨架，例如标题、段落、表单、列表。

### CSS：样式
控制视觉呈现，包括布局、颜色、间距、响应式。

### JavaScript：交互与逻辑
处理事件、数据、业务流程与动态更新。

### DOM 是什么
DOM（Document Object Model）是浏览器把 HTML 解析后形成的对象树。JS 通过 DOM API 操作页面。

## 浏览器如何理解三者

1. 解析 HTML 得到 DOM
2. 解析 CSS 得到样式规则
3. 组合计算渲染页面
4. 执行 JavaScript，可能修改 DOM，再触发更新

## 技术关系

| 能力 | 作用 | 缺失后的问题 |
|---|---|---|
| HTML | 内容结构与语义 | 页面无骨架 |
| CSS | 视觉与布局 | 页面难用难看 |
| JavaScript | 交互与逻辑 | 页面静态不可交互 |
| DOM | JS 与页面沟通桥梁 | 无法精准控制界面 |

## 为什么 React/Vue 也不能跳过原生基础

- React/Vue 最终仍要渲染到 DOM
- 组件事件本质上还是浏览器事件模型
- 性能问题常落在渲染与 DOM 更新机制

## 学习建议

- 至少能独立完成：表单页、列表页、弹窗交互
- 熟悉：事件冒泡、DOM 查询、常见布局（Flex/Grid）
- 把“框架语法”翻译回“浏览器行为”来理解

## 小结

第一层是整套体系的地基。框架能力本质是对原生能力的组织和抽象，不是替代。
