# 06 SPA、前端路由与状态管理

> 所属层级：**第五层：应用组织层**。

## 问题背景

当页面增长为多视图应用时，问题从“写页面”变成“组织应用”。

## 核心解释

### SPA 是什么
单页应用（Single Page Application）：首次加载一个壳，后续通过前端路由切换视图，不整页刷新。

### 传统多页面 vs SPA

| 模式 | 页面切换 | 体验 |
|---|---|---|
| 多页面 | 每次请求新 HTML | 切换成本高 |
| SPA | 前端路由切换组件 | 交互更流畅 |

### 前端路由是什么
把 URL 映射到前端视图组件。
- React 常见：React Router
- Vue 常见：Vue Router

### 状态管理是什么
统一管理跨组件共享数据。
- React 生态：Redux / Zustand
- Vue 生态：Pinia

### props / state / store 区别
- props：父传子输入
- state：组件内部状态
- store：全局或模块共享状态

## 与上下层关系

- 依赖第三层：组件体系（React/Vue）
- 被第六层整合：Next/Nuxt 通常内建更多组织约定

## 小结

第五层回答“应用怎么组织”。路由与状态管理不是 UI 框架替代品，而是应用规模提升后的必需机制。
