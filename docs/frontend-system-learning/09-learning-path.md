# 09 现代前端学习路线（按目标分阶段）

> 所属层级：**第七层：学习方法层**。

## 问题背景

“先学哪个”比“学什么”更影响效率。

## 通用阶段路线

### 阶段 A：基础层（必修）
- HTML 语义结构
- CSS 布局（Flex/Grid）
- JavaScript 基础与 DOM 交互

### 阶段 B：语言增强层
- 在会写 JS 后引入 TypeScript
- 重点掌握类型标注与接口建模

### 阶段 C：UI 框架层
- React 或 Vue 选一个主线
- 掌握组件化、状态、生命周期/副作用

### 阶段 D：工程化层
- 学 Vite：dev、build、插件、环境变量

### 阶段 E：应用组织层
- 路由、状态管理、模块划分、组件通信

### 阶段 F：应用框架层
- 根据需求学 Next.js 或 Nuxt.js
- 理解 CSR/SSR/SSG 的取舍

## 为什么学习从下往上、做项目从上往下

- 学习：地基决定上限，先建立因果理解
- 做项目：先看目标场景，再反推技术组合

## 按目标给路线

### 目标一：普通网页
基础层 -> 少量 JS 交互 -> 可选 Vite

### 目标二：后台管理系统
基础层 -> TS -> React/Vue -> 路由/状态 -> 工程化深化

### 目标三：官网/作品集
基础层 -> 框架基础 -> Next/Nuxt（SSG 优先心智）

### 目标四：复杂 Web App
全七层都要，重点在状态管理、模块边界、性能与协作

### 目标五：现代全栈应用前端部分
在目标四基础上，重点加强 Next/Nuxt 应用框架思维

## 小结

高效路线是“分层推进 + 目标驱动”。不要一上来追框架高级 API。
