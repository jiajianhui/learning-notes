# 01 前端全景图：从“页面”到“应用”

> 所属层级：**导论（跨层）**，用于串联七层体系。

## 问题背景

你可能会问：
- 前端不就是写页面吗，为什么现在这么复杂？
- React/Vue、Vite、Next/Nuxt 为什么都叫“前端”，但看起来不是一类东西？

## 核心解释

### 1) 前端最初为什么像“页面制作”

早期 Web 的核心是信息展示：
- HTML：把内容放进页面
- CSS：让页面好看
- JavaScript：加一点交互

这对应七层中的**第一层基础层**。

### 2) 现代前端为什么变成“应用开发”

用户期望变了：
- 页面无需整页刷新
- 界面像桌面软件一样可交互
- 功能模块多、状态复杂

于是前端要处理的不只是“显示”，而是“应用行为”，引出了：
- 第三层：React/Vue（组件化）
- 第五层：路由与状态管理（应用组织）
- 第六层：Next/Nuxt（完整应用框架）

### 3) 什么是前端工程化

当项目规模变大，单纯写 JS 文件不够：
- 需要模块化
- 需要开发服务器
- 需要打包优化
- 需要统一构建流程

这就是**第四层工程化层**，Vite 属于这一层。

## 技术关系（跨层图）

```text
应用框架（Next/Nuxt）
    ↓ 依赖
UI 框架（React/Vue）
    ↓ 依赖
语言增强（TypeScript）
    ↓ 依赖
基础能力（HTML/CSS/JS/DOM）

工程化（Vite）横向支撑：开发、构建、打包
应用组织（路由/状态）负责把页面变成应用
```

## 学习建议

- 先区分“类别”再学“细节”：基础 / 框架 / 工具 / 应用框架。
- 每遇到新名词先问三件事：
  1. 它在第几层？
  2. 它解决什么问题？
  3. 它依赖谁、被谁依赖？

## 小结

现代前端不是突然变复杂，而是从“页面制作”演化成“应用开发”。七层体系能把复杂度拆开：每层各司其职，组合成完整项目。
