# 术语表（通俗版）

- **HTML**：网页骨架，负责内容结构。
- **CSS**：网页外观，负责样式和布局。
- **JavaScript**：网页行为，负责交互和逻辑。
- **TypeScript**：给 JavaScript 加“类型护栏”。
- **DOM**：浏览器里的页面对象树，JS 操作页面靠它。
- **BOM**：浏览器对象模型，如 `window`、`location`。
- **React**：用于构建 UI 的框架/库生态核心。
- **Vue**：渐进式前端框架，强调易上手与响应式。
- **Vite**：前端开发与构建工具。
- **Next.js**：基于 React 的应用框架。
- **Nuxt.js**：基于 Vue 的应用框架。
- **组件**：可复用的 UI 模块。
- **状态**：会变化的数据。
- **props**：父组件传给子组件的数据。
- **store**：跨组件共享状态的集中容器。
- **路由**：URL 到页面/组件的映射规则。
- **SPA**：单页应用，前端路由切换视图。
- **CSR**：客户端渲染，主要在浏览器生成页面。
- **SSR**：服务端渲染，服务器先产出 HTML。
- **SSG**：静态生成，构建时生成静态页面。
- **构建工具**：把源代码处理为可运行产物的工具。
- **开发服务器**：本地开发时启动的预览与热更新服务。
- **打包**：把多个模块合并优化输出。
- **依赖**：项目运行或开发需要的外部包。
- **入口文件**：应用启动的起点文件。
- **package.json**：项目依赖、脚本、元信息配置文件。
- **tsconfig.json**：TypeScript 编译配置。
- **vite.config.ts**：Vite 行为与插件配置。
- **框架**：提供结构化开发范式与约定的工具集。
- **库**：提供某类能力，使用方式更自由。
- **工具链**：从开发到构建的一整套工具组合。
- **工程化**：用规范和工具提升开发效率与质量。
- **Vanilla JS**：不依赖框架的原生 JavaScript 开发。
- **Vanilla TS**：不依赖 UI 框架的 TypeScript 开发。

## 小结

术语要结合“层级 + 场景”理解，不要孤立记忆。
