# 工具与运行环境学习入口

这个目录负责补齐写代码之外的基础工具：终端、Shell、CLI 和 Codex。

主线不是收集命令，而是逐步看懂一段代码怎样从自己的电脑走到线上：

```text
在 Terminal 中输入命令
-> Shell 解释命令
-> CLI 完成具体工作
-> 工具输出结果
```
